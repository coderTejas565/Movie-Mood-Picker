# 🎬 Movie Mood Picker

Movie Mood Picker is a **JavaScript fundamentals project** that recommends movies based on the user’s mood.  
The goal of this project is to practice **core frontend concepts** while building something interactive and user-friendly.

> *“Tell me how you feel. I’ll find a movie that matches it.”*

## 🧠 Project Overview

This app allows users to:
1. Select their current mood (Comedy, Action, Drama, Romantic)
2. Receive a movie recommendation based on that mood
3. Browse through recommendations using **Next / Previous** buttons
4. View movie details fetched dynamically from the **OMDB API**

The project focuses on **clarity, simplicity, and learning-by-building**.

Open the project folder:
cd movie-mood-picker


Open index.html in your browser
(No build tools or dependencies required)

🔑 API Usage
This project uses the OMDB API to fetch movie data.

API is accessed directly from the frontend

Suitable for learning and demo purposes

In production apps, API keys should be handled securely via a backend
